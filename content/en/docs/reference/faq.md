## Is Collab.codes an ERP?

No. Collab.codes is a platform for creating and evolving business applications. It can be used for ERP-like workflows, but it is not limited to a fixed ERP model.

## Is it only a code generator?

No. Code generation is only part of the story. The platform also includes runtime, collaboration, managed services, governance, and AI-assisted maintenance.

## Are Collab Aura and Collab Forge mandatory?

No. They are opinionated defaults used by the reference runtime. The master config, master frontend, and master backend should remain customizable.

## Does no lock-in mean customers should self-host everything?

No. No lock-in means customers have a real exit path. Many customers may still prefer managed Collab.codes services because they reduce operational complexity.

## Where do Studio and Build fit?

Studio belongs to creation and maintenance. Build and publication prepare delivery targets. Both deserve dedicated documentation beyond the runtime pages.

## Can the platform use different LLM providers?

Yes. Collab LLM can route through multiple providers and can expose a standardized endpoint strategy.
