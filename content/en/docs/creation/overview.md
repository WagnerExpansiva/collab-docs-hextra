Creation is the Collab.codes dimension responsible for turning business intent into application behavior.

It is not limited to the first generation of code. It also includes how the software is reviewed, changed, localized, versioned, and evolved over time.

## What Creation includes

Creation includes:

- Studio;
- page comments and suggestions;
- AI-assisted maintenance;
- local drafts;
- pull requests;
- Page Genome;
- component choices;
- i18n by page;
- publishing workflows.

## Why it exists

Business software changes constantly. If every change requires users to leave the application, explain the context again, and wait for a traditional development cycle, the product becomes slow to evolve.

Creation brings the change process closer to the place where the work happens.

## Relationship with Runtime

Creation defines what should exist.

Runtime makes it executable.

The two dimensions must stay connected. A generated page needs frontend behavior, backend routines, permissions, monitoring, auditability, and a path to production.

## Relationship with Collaboration

Creation also depends on collaboration. Suggestions, comments, approvals, tasks, and AI agents need context from the application.

When the application keeps this context close, the change process becomes easier to understand and review.
