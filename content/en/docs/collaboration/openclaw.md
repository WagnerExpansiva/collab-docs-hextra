OpenClaw can be used as an optional integration space for external automation, research, communication channels, and support workflows.

It should be presented as an integration opportunity, not as a mandatory dependency for Collab.codes.

## How it relates to Collab Messages

The relationship can work in both directions.

Collab Messages can call external automation when a task needs research, email, WhatsApp, or another channel. External automation can also return to Collab Messages when human intervention is needed.

## What to use it for

OpenClaw can be useful for:

- external research;
- communication with channels outside the application;
- support escalation;
- automation tasks that do not belong inside the business runtime;
- agent experiments that need a separate execution space.

## Product boundary

Collab.codes should keep the customer application coherent.

OpenClaw is valuable when external automation enriches the workflow without making the core application depend on it.
