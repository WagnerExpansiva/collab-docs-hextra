Collab Aura é o master frontend opinado usado no exemplo de referência atual do Collab.codes.

Ele é desenhado para aplicações empresariais operacionais, não para páginas estáticas simples de marketing.

## O que Aura fornece

Aura fornece estrutura frontend para:

- aplicações SPA/PWA-ready;
- carregamento por rota;
- Web Components com Lit 3;
- organização de páginas;
- Page Genome;
- contratos reutilizáveis de componentes;
- comunicação BFF.

## Quando usar

Use Aura para experiências com comportamento de aplicação, como plataformas internas, ERPs, CRMs, dashboards, operações de catálogo, suporte e workflows transacionais.

## Customização

Aura é um padrão opinado, não um lock-in.

Projetos devem poder usar outro master frontend quando o cliente ou contexto de produto exigir.

## Conceitos relacionados

- Runtime;
- BFF;
- Page Genome;
- Moléculas Lit 3;
- SPA/PWA.
