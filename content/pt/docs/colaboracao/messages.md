Collab Messages é a camada de comunicação para pessoas, tasks, agentes e trabalho contextual dentro de uma aplicação cliente.

Ele está mais próximo de uma superfície de workflow empresarial do que de um produto de chat desconectado.

## Por que existe

O trabalho empresarial frequentemente sai da aplicação.

Uma dúvida começa no sistema, vai para email ou WhatsApp, vira uma task em outro lugar e perde o registro, a permissão, a tela e o contexto de decisão que tornavam aquilo importante.

Collab Messages é desenhado para manter mais desse trabalho dentro da experiência da aplicação.

## O que pode apoiar

Collab Messages pode apoiar:

- comunicação entre usuários;
- orquestração de tasks;
- participação de agentes de IA;
- suporte contextual;
- mini apps;
- links úteis para onboarding;
- integração com espaços externos de automação, como OpenClaw.

## Relação com Runtime e Studio

Messages pode aparecer na aplicação runtime e no Studio.

Isso importa porque colaboração é útil tanto quando as pessoas executam o processo de negócio quanto quando sugerem mudanças na própria aplicação.
