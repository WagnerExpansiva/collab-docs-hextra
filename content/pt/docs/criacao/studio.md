Studio é a experiência do Collab.codes para criar e manter aplicações cliente.

O modelo desejado é contextual: o Studio deve permanecer perto da aplicação, para que usuários e agentes de IA entendam a tela, o registro, o workflow e a intenção de negócio por trás de uma mudança.

## Quando usar

Use o Studio quando um time precisa:

- sugerir uma mudança diretamente de uma página da aplicação;
- comentar uma tela com contexto de negócio;
- rascunhar uma mudança assistida por IA;
- enviar a mudança para revisão;
- publicar o resultado com a política correta.

## Como funciona conceitualmente

O Studio é desenhado como uma camada client-side carregada próxima da experiência da aplicação do cliente.

Uma mudança pode começar onde o usuário percebe o problema. Ela pode ser rascunhada localmente, revisada, movida para controle de versão e publicada de forma automática ou manual conforme o processo do cliente.

## Governança

Edição contextual não significa edição sem controle.

O fluxo deve respeitar:

- permissões;
- aprovações;
- ambientes;
- pull requests;
- auditoria;
- políticas de publicação.

Empresas pequenas podem usar um caminho mais leve. Organizações maiores podem adicionar camadas de aprovação.
